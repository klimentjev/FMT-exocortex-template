# Capture: Различение "Операционная vs системная модель роли"

## Контекст
Сессия анализа стратегического тупика основателя проектов НИФ/ФиЯ при переходе от центральной роли к архитекторской.

## Различение

| Операционная модель | Системная модель |
|---------------------|------------------|
| «Я — центр, без меня не работает» | «Я — архитектор условий, работает без меня» |
| Каждое решение требует присутствия субъекта | Критерии и процессы определены заранее |
| Масштабирование = рост нагрузки на субъекта | Масштабирование = рост автономных контуров |
| Метрика: количество обращений лично ко мне | Метрика: количество контуров, работающих 30+ дней без меня |

## Тесты

1. «Если я пропаду на месяц — система остановится?»
   - Да → операционная модель
   - Нет → системная модель работает

2. «Я меняю результат или меняю условия для результата?»
   - Меняю результат → операционная
   - Меняю условия → системная

## Индикаторы соскока
- «Быстрее сам сделаю»
- «Нужно объяснить лично»
- Редактирование перед публикацией
- Вмешательство в конфликт

## Протокол при срабатывании
STOP → удалить результат → анализ системы → возврат задачи исполнителю.

## Онтологический вызов
Успех системной модели выглядит как «я не нужен». Лечится переименованием метрики: не «быть нужным», а «создавать возможности для автономии других».
