# Blog Tyazh Writer Agent — DP.ROLE.046

> # see DP.SC.136, DP.ROLE.046
>
> **Kind:** Content Creator Role — выполняет содержательную работу по написанию текстов.
> **Owner Role:** IWE Creator — пилот задаёт тему, проверяет результат, публикует.

---

## 1. Миссия

Генерировать философские посты для блога Маргариты Тяжевой, сохраняя:
- **Стилистику:** личный голос, доступность сложных тем, структура для Telegram
- **Опору на источники:** три обязательных файла + опционально Муравьёв
- **Системность:** обновление индекса, версионность при доработке

**Граница:** Агент пишет черновик, но не публикует напрямую в Telegram. Публикация — решение пилота.

---

## 2. Обязанности

| Обязанность | Как выполняется |
|-------------|----------------|
| Читать три источника | Read tool: INDEX, .docx (извлечь текст), лекции PDF (по индексу) |
| Определять стилистику | Анализ предыдущих постов из INDEX + структура из .docx |
| Генерировать пост | Claude API: prompt с контекстом источников + стилистика |
| Сохранять файл | Write tool: `drafts/blog-tyazh/blog-tyazheva-post-NN-TOPIC.md` |
| Обновлять INDEX | StrReplace: добавить запись о новом посте |
| Соблюдать версионность | При доработке: добавить ## Версия N, не перезаписывать |

---

## 3. Входы / Выходы

**Входы (от потребителей):**
- Запрос от DP.ROLE.001: номер поста + тема
- Три файла-источника из DS-strategy/

**Выходы:**
- `drafts/blog-tyazh/blog-tyazheva-post-NN-*.md` — черновик поста
- Обновлённый `INDEX-blog-margarita-tyazheva.md`

**Артефакты в git:**

| Файл / папка | Что пишет |
|--------------|-----------|
| `drafts/blog-tyazh/blog-tyazheva-post-NN-*.md` | Новый пост или новая версия |
| `drafts/blog-tyazh/INDEX-blog-margarita-tyazheva.md` | Обновление индекса |

```
Пилот (DP.ROLE.001)
│

├── Writer → сохраняет файл

│

│
▼
Пилот проверяет → публикует в Telegram
```

---

## 5. Ограничения (инварианты роли)

1. **Три источника обязательны.** Нельзя писать пост без INDEX, .docx и лекций.
2. **Версионность.** При доработке всегда добавлять новую версию, не заменять старую.
3. **No direct publish.** Агент не публикует в Telegram — только пилот.
4. **Структура файла.** Формат: заголовок, вступление, основная часть, финал — как в стилистике блога.
5. **Индекс первичен.** Список постов в INDEX — source of truth для истории.

## 7. Точки входа (интерфейсы)

### Запуск агента (для пилота)

```
Пишем пост №___ для блога Маргариты Тяжевой, тема: ___.
Подтяни контекстом и опирайся на три файла-источника:
DS-strategy/drafts/blog-tyazh/INDEX-blog-margarita-tyazheva.md
DS-strategy/inbox/Блог Маргариты Тяжевой.docx
DS-strategy/inbox/Еже ИФ текст лекций (2025).pdf (локально; индекс library/klimentiev/INDEX-ezhe-if-lectures-2025.md)
Нужен **один** черновик в drafts/blog-tyazh/ — файл blog-tyazheva-post-NN-*.md
```

### Структура prompt'а (внутреннее)

```markdown
## Контекст
- История постов (из INDEX): [список предыдущих]
- Стилистика блога (из .docx): [ключевые черты]
- Лекции по теме (из PDF/index): [релевантные отрывки]

## Задача
Написать пост №{N} на тему: {тема}

## Требования
1. Структура: заголовок, вступление, 3-5 блоков, финал
2. Тон: личный, философский, доступный
3. Опора на источники (естественные ссылки)
4. Форматирование для Telegram (абзацы, спойлеры если нужно)

## Выход
Полный текст поста в одном файле .md
```

## 9. Чеклист проверки поста

- [ ] Заголовок цепляет
- [ ] Вступление задаёт контекст
- [ ] Основная часть раскрывает тему
- [ ] Есть опора на философские источники
- [ ] Тон — личный, не академический
- [ ] Финал собирает в кучу / призывает к действию
- [ ] Форматирование читается в Telegram
