# DP.SC.136 — Агент для блога Маргариты Тяжевой

## Правило (инвариант)

- [ ] Каждый пост основан на трёх файлах-источниках: INDEX-blog-margarita-tyazheva.md, Блог Маргариты Тяжевой.docx, Еже ИФ текст лекций (2025).pdf (или их индексах).
- [ ] Пост соответствует стилистике блога: философская глубина, доступность, личный голос автора, структура для Telegram.
- [ ] Результат сохраняется в drafts/blog-tyazh/blog-tyazheva-post-NN-*.md (единый файл, без параллельного *-TG.md).
- [ ] INDEX-blog-margarita-tyazheva.md обновляется после создания поста.
- [ ] При доработке: новая версия добавляется как ## Версия N, предыдущие не перезаписываются.

## Обещание

**Кому:** DP.ROLE.001 Создатель IWE (пилот, автор блога).

**Зачем:** Автоматизировать регулярную задачу написания постов (1 ч по понедельникам) с сохранением качества, стилистики и связности с предыдущими материалами.

**Что получит:**
1. Черновик поста в `drafts/blog-tyazh/` с полным текстом для Telegram.
2. Обновлённый индекс `INDEX-blog-margarita-tyazheva.md`.
3. Пост, прошедший проверку по чеклисту: тема раскрыта, стиль соответствует, источники использованы.

**Триггер:**
- Команда пользователя: «Пишем пост №___ для блога Маргариты Тяжевой, тема: ___»
- Или регулярный понедельник — Day Open выводит шаблон-напоминание.

**Время отклика:** ≤15 минут на черновик (для модели Sonnet 4).

**Режим отказа:**
- Источники недоступны → сообщить пользователю, каких файлов не хватает.
- Тема не соответствует стилю блога → уточнить у пользователя или предложить альтернативную формулировку.
- Не удалось сохранить в drafts/ → fallback: вывести текст в чат + предупреждение.

## Заметки

**Когда уместен этот паттерн:**
- Регулярная задача генерации контента с чёткой стилистикой
- Доступны источники знаний (лекции, тексты, предыдущие посты)
- Нужно сохранять индекс и версионность

**Когда НЕ уместен:**
- Разовый пост — проще написать вручную
- Нет доступных источников — агент не сможет обеспечить качество
- Тема выходит за рамки компетенции (не философия) — стилистика не применима
