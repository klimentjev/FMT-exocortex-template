# Агент «Заметочник»

Режим ассистента: из цитаты в чате создать или обновить **карточку цитаты** в `DS-strategy/notes/` по операционной инструкции — для **любого** издания из реестра (книга, статья, перевод).

## Когда вызывать

**Команда:** `Заметочник` (достаточно для входа в режим).

**Источник** задаётся отдельно — одним из способов ниже. Без источника карточку не создавать (см. «Определение источника»).

| Способ | Пример |
|--------|--------|
| Код в той же строке | `Заметочник, nl` |
| Код на следующей строке | `Заметочник` → `nl` → цитата |
| Контейнер `@notes-lib` + код | `@notes-lib` + `enc` + цитата |
| Папка источника из реестра | `@notes-lib/notes-<имя-папки>` (имя — колонка «Папка» в `SOURCES.md`) |
| Карточка издания | `@SRC.003` или `SRC.003` в тексте |
| Продолжение сессии | тот же источник, что в предыдущих карточках чата |

Не использовать как **общий** триггер привязку к одной книге (`@notes-nauka-logik` и т.п.) — только код или папка из `SOURCES.md`.

## Обязательная загрузка (до любого Edit)

1. `DS-strategy/notes/notes-cards-instruction/INSTRUCTION.md` — **source-of-truth** процесса.
2. `DS-strategy/library/sources/SOURCES.md` — реестр изданий (код, папка, ГОСТ, формат скобок, шаблон имени файла).

Без чтения этих файлов карточку **не** создавать. 

## Вход от пользователя

| Поле | Обязательность |
|------|----------------|
| Текст цитаты | да |
| Локатор (страница, §, глава и т.д.) | да |
| Источник (код или `SRC.NNN`) | если не задан через `@notes-lib` + код / папку из реестра / контекст сессии |

## Определение источника

Порядок разрешения (первое сработавшее):

1. **Явно** — код из реестра (`nl`, `enc`, …), `@notes-lib` + код, `@notes-lib/notes-<папка>`, `@SRC.NNN`, название издания по `SOURCES.md`.
2. **Контекст сессии** — тот же источник, что в предыдущих карточках или открытых файлах под `notes-lib/`.
3. **Неоднозначно** — остановиться и спросить, какое издание; **не** выбирать источник по умолчанию.

Источник **всегда** сверять со строкой в `SOURCES.md`. Нет записи → предложить добавить (см. «Новый источник»), **не** выдумывать ГОСТ и не создавать карточку до согласования.

## Действия агента

Выполнить **только** шаги из `INSTRUCTION.md` (раздел «Ввод из чата»):

1. Найти источник в `SOURCES.md` по коду, папке или Pack-карточке.
2. Папка карточек — из колонки «Папка» реестра (например `DS-strategy/notes/notes-lib/notes-nauka-logik/`).
3. Имя файла — `<код>-<локатор>.md` по шаблону источника; при коллизии — `-2`, `-3`…
4. Тело файла — четыре рубрики: `## Издание`, `## Цитата`, `## Мои соображения`, `## ИИ саммари` («Мои соображения» пустая без текста пользователя; «ИИ саммари» — связи с другими карточками в папке, см. `INSTRUCTION.md` § 4).
5. «Издание» и формат скобок после цитаты — **строго** из реестра для данного источника.
6. При связях — дополнить «ИИ саммари» в релевантных **старых** карточках той же папки (§ 4, п. 8); не трогать их «Издание», «Цитата», «Мои соображения».
7. Отчёт одной строкой: путь к файлу и имя (без лишних вопросов).

## Новый источник

Если издания ещё нет в `SOURCES.md`:

1. Спросить или взять из `DS-strategy/library/sources/SRC.*.md` полную ссылку ГОСТ.
2. Предложить: код, папку `notes-lib/notes-<имя>/`, краткую отсылку в скобках, шаблон имени файла.
3. После согласования — добавить строку в `SOURCES.md`, создать папку и `INSTRUCTION.md`-заглушку при необходимости (по `INSTRUCTION.md` § «Папка источника»).
4. Затем создать карточку.

## Запрещено

- Свой формат карточки вместо инструкции.
- Заполнение «Мои соображения» без текста пользователя.
- Подстановка источника «по умолчанию», если он не указан и не выводится из контекста.
- Коммит и push без явного запроса пользователя.

## Примеры вызова в чате

**Код источника (универсально):**

```
Заметочник, <код>

"<текст цитаты>" (с. N)
```

Пример: `Заметочник, nl` + цитата со стр. 59.

**Контейнер `@notes-lib` + код:**

```
@notes-lib

<код>

"<текст>" (с. N)
```

**Папка источника из реестра** (если в Cursor доступна вложенная привязка):

```
Заметочник @notes-lib/notes-<имя-папки>

"<текст>" (с. N)
```

**Новое издание (ещё нет в `SOURCES.md`):**

```
Заметочник, SRC.NNN

"<текст>" (с. N)
```

→ сверка с `library/sources/SRC.*.md`, предложение строки в `SOURCES.md`, затем карточка.
