# Day Close — ЖЖ (LiveJournal)

> Hook: `day-close.before`. Выполняется перед началом протокола Закрытия дня.

## Опрос перед итогами (AskQuestion)

Перед черновиком Day Close — **обязательный опрос** через `AskQuestion` (не текстом в чате). Дождаться ответов; без них не переходить к записи итогов.

### Вопрос 1 — ЖЖ (LiveJournal)

**Заголовок опроса:** `Day Close — ЖЖ и заметки (DD.MM.YYYY)`

**Prompt:** «ЖЖ (LiveJournal): пост по итогам дня — что с ним?»

| id | label |
|----|-------|
| `lj_written` | Уже написал пост в ЖЖ сегодня |
| `lj_will_write` | Напишу сам после Close (зафиксировать как обязательство) |
| `lj_skip` | Сегодня пропускаю — осознанно, без переноса |

При `lj_will_write` — в «Не забыто» итогов: обязательство написать ЖЖ.

### Вопрос 2 — заметки дня

Найти `DS-strategy/inbox/zametki-DD-MM-YYYY.md` (дата = сегодня). Если файла нет — вопрос не задавать.

**Prompt:** «Заметки дня: `inbox/zametki-DD-MM-YYYY.md` [пустой / N строк]. Что сделать с файлом?»

| id | label |
|----|-------|
| `zam_delete` | Удалить (пустой или обработан) |
| `zam_keep` | Оставить как заготовку |
| `zam_fill_later` | Оставить — заполню сам позже |
| `zam_archive` | Перенести содержимое → archive/notes, файл удалить |
| `zam_other` | Другое (напишу в чате) |

Выполнить выбор **до** commit Day Close.

### Подсказка для поста ЖЖ (если пишет)

- Что сегодня получилось?
- Кому и за что я благодарен?
- Подсчёт часов по задачам — из сессий / стоп-отчётов журнала.
