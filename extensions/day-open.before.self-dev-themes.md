# Day Open — темы саморазвития из day-rhythm-config

> Hook: `day-open.before`. Читать при шаге 3 (Саморазвитие).

## Правило

Источник: `memory/day-rhythm-config.yaml → day_open.self_dev_backlog`.

1. **Жёсткий carry** из вчерашнего «Завтра начать с» / незакрытый слот саморазвития → оставить carry в плане дня; темы из backlog **не вытеснять**.
2. Если carry по саморазвитию нет (или явно закрыт) → в слот 1 и секцию «Саморазвитие» поставить следующую тему из `self_dev_backlog` (сейчас: **псевдо-я и подлинное я**, режим `reflect`).
3. В compact dashboard и DayPlan формулировать слот как размышление, не как обязательный черновик D-NNN (если `mode: reflect`).
4. После использования темы в день — краткая пометка в Session Log / итогах; тему из backlog не удалять, пока пилот не скажет снять.
