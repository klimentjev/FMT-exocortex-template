# Day Close — безопасный бэкап exocortex/

> Hook: `day-close.checks`. После `day-close.sh` (шаг 5) и перед финальным коммитом (шаг 10b).

## Правило

Бэкап `memory/` → `{{GOVERNANCE_REPO}}/exocortex/` — **только upsert** (обновить/добавить). Скрипт `scripts/day-close.sh` **не должен** использовать `rsync --delete`.

## Проверка агента (обязательно)

После шага 5 посмотреть `git status` в governance-репо по пути `exocortex/`:

1. Если много строк `D exocortex/...` (массовые удаления) → **не стейджить и не коммитить**.
2. Сразу: `git restore exocortex/` (или точечный restore удалённых файлов).
3. В «Не забыто» / отчёт Close: кратко «бэкап пытался снести файлы в exocortex — откатил; проверить `day-close.sh`».
4. Коммитить из `exocortex/` только явно обновлённые файлы дня (например `MEMORY.md`, `CLAUDE.md`), списком путей — не `git add exocortex/`.

Очистка устаревших файлов в `exocortex/` — только по явному решению пилота, не автоматически.
