# Day Open — меню дня из diet.md

> Hook: `day-open.before`. Выполняется при шаге 7a (запись DayPlan).

## БЛОКИРУЮЩЕЕ: фрагмент меню в DayPlan

Источник: `memory/day-rhythm-config.yaml → diet_menu`.

### Алгоритм

1. Прочитать `diet_menu.source` (по умолчанию `DS-strategy/docs/health/diet.md`).
2. Определить номер дня цикла **N** (1–7):
   - `week_start: monday` → пн=1, вт=2, ср=3, чт=4, пт=5, сб=6, **вс=7**.
3. Из файла меню извлечь секцию **`### День N`** целиком (от заголовка до следующего `### День` или `##`, не сокращать).
4. Вставить в `current/DayPlan YYYY-MM-DD.md` блок **после** «План на сегодня», **до** «Календарь» (если есть):

```markdown
<details>
<summary><b>Меню дня (diet.md · День N)</b></summary>

> Источник: [diet.md](относительная ссылка из DayPlan в docs/health/diet.md) · недельный цикл: пн=День 1 … вс=День 7

[текст секции ### День N из diet.md — дословно]

</details>
```

5. Если секция уже есть в DayPlan с тем же N — не дублировать.
6. Если `diet.md` или `### День N` не найден — пункт в «Требует внимания», DayPlan создавать без меню.

### Шаблон плана дня

Секция **«Меню дня»** — обязательная часть DayPlan в этом IWE (наряду с планом РП). Не заменяет календарь и не смешивается с блоком «План на сегодня».
