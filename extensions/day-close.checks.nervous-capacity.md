# Day Close — сверка нервного контура (ёмкость)

> Hook: `day-close.checks`. Выполняется при записи «Итоги дня» (шаг 9a) и как check перед архивацией DayPlan.
> Пара к Open: `extensions/day-open.before.nervous-capacity.md`.
> **Промпт агента (канон):** `DS-strategy/library/nervous-capacity/PROMPT.md` § Close — **Read и исполнить** при каждом Day Close.

## БЛОКИРУЮЩЕЕ: блок ёмкости в итогах дня

Day Close **не считать полным**, пока в «Итоги дня» нет секции **«Нервный контур (ёмкость · вечер)»** (шаблон ниже).  
Исключение: пилот явно сказал «закрой без ёмкости» → пункт в «Не забыто» / «Требует внимания», цвет вечера = `н/д`.

### 0. Промпт (обязательный шаг)

1. `Read` файл `DS-strategy/library/nervous-capacity/PROMPT.md` (§ Close).
2. Сверить утренний блок DayPlan с фактами дня; недостающее — форма из PROMPT § Close (пилот).
3. Классифицировать утро→вечер и доминирование (перегруз / защита / оба) **в рамке промпта**.
4. Записать вечерний блок + согласовать «Завтра начать с» с выводом по ёмкости.

### 1. Куда смотреть

| Источник | Что взять |
|----------|-----------|
| Утренний блок в сегодняшнем DayPlan | цвет дня, режим, следствие для 🔴 |
| Факты дня (таблица РП, mini-wp JSON, календарь) | было ли касание / show-ready / удар в паре / recovery |
| Пилот (если нет) | сон дневной/вечернее самочувствие; АД если мерил; слово аффекта сейчас |
| `fitnes2.md` | запись тренировки/восстановления за сегодня |

### 2. Что фиксировать вечером

| Поле | Смысл |
|------|--------|
| Цвет утро → цвет вечер | динамика ёмкости за день |
| Удар за день | да/нет + тип (пара / тело / стыд от нулей / иное) |
| Внешняя оценка | сделан акт / skip по протоколу recovery / skip без протокола (долг) |
| Перегруз vs защита | что доминировало сегодня (кратко) |
| Вывод на завтра | один следующий шаг по ёмкости + по якорю денег/show-ready |

### 3. Критерии оценки вечера

Те же 5 маркеров, что утром (сон — если релевантен «как сейчас / готовность к ночи»; иначе опора на аффект + тело + тяга к оценке + факт удара).

Цвет вечера:

- **🔴** — сильное истощение, желание обнулить, АД/боль в красной зоне, или серия пустых Close без recovery-метки;
- **🟡** — усталость, но контроль есть; solitary возможен;
- **🟢** — есть запас на один акт предъявления завтра утром.

Сверка утро→вечер:

| Паттерн | Вывод |
|---------|--------|
| 🟢→🟢 и 0 касаний при обязательном якоре | скорее **защита** (ёмкость была) |
| 🔴→🔴 или удар→0 денег | **перегруз / протокол**; не морализовать |
| 🟡→🔴 после догона WIP | перегруз от плана; завтра срез WIP |
| 🔴 утро, но день ушёл в Strategy/инфру | **ложное восстановление** (запрет Open нарушен) |

### 4. Выводы → завтра

Обязательная строка в «Завтра начать с» или в блоке ёмкости:

| Вечер | Завтра (ёмкость) |
|-------|------------------|
| 🟢 | Светофор утром; при 🟢 — якорь денег допустим первым |
| 🟡 | Один акт оценки максимум; не оба контура |
| 🔴 | Сначала сон/восстановление; касание только после утреннего 🟢/🟡 без удара |
| Был удар в паре | Завтра деньги = micro или skip до светофора |

Пустой Close «без данных» при нуле по 🔴 **без** строки recovery = нарушение: дописать «ёмкость: факт не снят» в «Не забыто».

### 5. Шаблон в «Итоги дня»

Вставить **после** таблицы РП / мультипликатора, **до** «Что нового узнал» (или сразу после «Что нового», если так удобнее — но до «Завтра начать с»):

```markdown
### Нервный контур (ёмкость · вечер)

> Протокол: `extensions/day-close.checks.nervous-capacity.md` · промпт: `library/nervous-capacity/PROMPT.md`

| | Утро | Вечер |
|---|------|-------|
| Цвет | 🟢/🟡/🔴 | 🟢/🟡/🔴 |
| Режим утра | рабочий / осторожный / recovery | — |

**Удар за день:** нет / пара / тело / стыд-нули / иное — _кратко_  
**Внешняя оценка:** акт сделан / skip по recovery / skip без протокола  
**Доминировало:** перегруз / защита / оба  
**Вывод на завтра:** _одна строка (ёмкость + деньги/show-ready)_
```
